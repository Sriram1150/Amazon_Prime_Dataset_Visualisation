📺 Amazon Prime TV Shows Dashboard — Tableau

An interactive Tableau dashboard for exploring Amazon Prime Video TV shows by genre, ratings, release year, country, and other content attributes.

📌 Project Overview

This project uses Tableau to transform Amazon Prime Video TV show data into an interactive visual analytics dashboard. The dashboard provides an overview of the content library and allows users to explore patterns across genres, ratings, release years, and geographic distribution.

🎯 Objectives

Analyze the distribution of TV shows available on Amazon Prime Video.

Explore shows by genre and rating.

Understand how the content library has changed across release years.

Analyze the geographic distribution of TV shows.

Provide an interactive dashboard for quick content insights.

📊 Dashboard Features

The Tableau dashboard includes visual analysis of:

Total TV Shows

Shows by Genre

Shows by Rating

Shows by Release Year

Country-wise content distribution

Interactive filters for exploring different segments of the dataset

Visual comparisons of content trends across categories
